# 授权失败：授权码不存在

> [!info] 导航 / Navigation
> [[文档中心]] · [[setup-options-level-pro|Options Level Pro 安装激活]]

**错误码 LICENSE_NOT_FOUND**

错误码：`LICENSE_NOT_FOUND`

未找到对应授权。常见原因是授权码复制不完整、前后带有空格，或者输入了其他产品的授权码。

## 处理步骤

1. 重新复制完整授权码。
2. 删除授权码前后的空格。
3. 确认当前授权对应 Options Level Pro。
4. 回到 ATAS 后重新加载指标。
