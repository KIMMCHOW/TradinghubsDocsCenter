# 授权与当前产品不匹配

> [!info] 导航 / Navigation
> [[文档中心]] · [[setup-options-level-pro|Options Level Pro 安装激活]]

**错误码 PRODUCT_MISMATCH**

错误码：`PRODUCT_MISMATCH`

当前授权不是 Options Level Pro 授权，无法用于激活本指标。

## 处理步骤

1. 检查购买的产品名称。
2. 登录 TradingHub 查看授权列表。
3. 复制 Options Level Pro 对应的授权码。
4. 回到 ATAS 后重新加载指标。
