# 授权已到期

> [!info] 导航 / Navigation
> [[文档中心]] · [[setup-options-level-pro|Options Level Pro 安装激活]]

**错误码 LICENSE_EXPIRED**

错误码：`LICENSE_EXPIRED`

当前授权已经超过有效期，因此无法继续获取 Options Level Pro 最新数据。

## 处理步骤

1. 登录 TradingHub。
2. 进入“我的授权”查看有效期。
3. 续费或购买新的正式授权。
4. 返回 ATAS 后重新加载指标。
