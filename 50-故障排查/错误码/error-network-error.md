# 无法连接授权或数据服务器

> [!info] 导航 / Navigation
> [[文档中心]] · [[setup-options-level-pro|Options Level Pro 安装激活]]

**错误码 NETWORK_ERROR**

错误码：`NETWORK_ERROR`

Options Level Pro 当前无法连接服务器，可能是本地网络、代理、DNS 或服务器临时异常。

## 处理步骤

1. 检查电脑网络是否正常。
2. 检查代理或 VPN 是否阻止连接。
3. 稍后重新加载指标。
4. 查看 TradingHub 服务状态或联系支持。
