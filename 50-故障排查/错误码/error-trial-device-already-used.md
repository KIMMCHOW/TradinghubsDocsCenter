# 该设备已经使用过免费试用

> [!info] 导航 / Navigation
> [[文档中心]] · [[setup-options-level-pro|Options Level Pro 安装激活]]

**错误码 TRIAL_DEVICE_ALREADY_USED**

错误码：`TRIAL_DEVICE_ALREADY_USED`

同一设备对同一产品只能使用一次免费试用，因此当前设备无法激活另一份试用授权。

## 处理步骤

1. 确认当前输入的是正确授权码。
2. 如需继续使用，请购买正式授权。
3. 正式授权不受试用设备限制。
