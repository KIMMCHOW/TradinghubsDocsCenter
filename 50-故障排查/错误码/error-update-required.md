# 当前版本需要更新

> [!info] 导航 / Navigation
> [[文档中心]] · [[setup-options-level-pro|Options Level Pro 安装激活]]

**错误码 UPDATE_REQUIRED**

错误码：`UPDATE_REQUIRED`

当前指标版本已经停止兼容最新服务，需要完成更新后继续使用。

## 处理步骤

1. 等待指标完成自动更新。
2. 完全退出 ATAS。
3. 重新启动 ATAS。
4. 如自动更新失败，请前往下载页面获取最新版本。
