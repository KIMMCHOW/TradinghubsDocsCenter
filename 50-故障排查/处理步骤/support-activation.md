# 激活问题处理步骤

> [!info] 导航 / Navigation
> [[文档中心]] · [[troubleshoot-options-level-pro|Options Level Pro 错误码]]

**检查授权码、网络、账号订单和到期状态。**

授权失败通常和授权码为空、过期、设备不匹配或首次验证网络不可用有关。

## 处理步骤

1. 在我的授权页面复制完整授权码，不要手动漏掉前后字符。
2. 确认授权状态为有效，并检查产品名称是否和正在激活的插件一致。
3. 首次激活需要联网；如果网络或防火墙拦截，请恢复连接后重新启用策略。
4. 如果提示设备不匹配，先到设备页检查绑定记录，必要时解绑旧设备后再激活。

---

## English

Activation failures usually involve a missing key, expiration, device mismatch, or unavailable network during first validation.

1. Copy the full key from My Licenses and avoid missing leading or trailing characters.
2. Confirm the license is active and that the product name matches the plugin being activated.
3. First activation needs internet access. If network or firewall blocks it, restore access and re-enable the strategy.
4. If a device mismatch appears, check the Devices page first and unbind the old device if needed.
