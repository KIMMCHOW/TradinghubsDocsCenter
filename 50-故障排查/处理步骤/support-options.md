# 数据工具问题处理步骤

> [!info] 导航 / Navigation
> [[文档中心]] · [[troubleshoot-options-level-pro|Options Level Pro 错误码]]

**检查登录、主题、数据更新时间和产品教程。**

Options Data Viewer 和 Squeezing Scanner 需要登录账号访问，请根据页面内的时间判断数据是否已更新。

## 处理步骤

1. 确认当前已登录 TradingHub 账号，并从账号主页或产品页进入数据工具。
2. 如果图表颜色或主题异常，切换一次主题后刷新页面。
3. 查看页面顶部的数据时间；盘后或数据更新延迟时，页面可能显示最后一次成功结果。
4. 使用文档中心的 Options Data Viewer 产品教程查看 Data Dashboard 和 Greeks Profile 说明。

---

## English

Options Data Viewer and Squeezing Scanner require account sign-in. Use the in-page timestamp to judge whether the data has updated.

1. Confirm you are signed in and open the data tool from the account home or product page.
2. If chart colors or theme look wrong, toggle theme once and refresh the page.
3. Check the data timestamp near the top. After hours or when updates are delayed, the page may show the last successful result.
4. Use the Options Data Viewer guide in the documentation center for Data Dashboard and Greeks Profile instructions.
